# AZK-CyberLab downloads

Official installers for **AZK-CyberLab** by Akili Za Kesho, the AI-coached network
and cybersecurity simulation lab for competency-based learning.

## Download

Go to **[Latest release](../../releases/latest)** and pick the file for your computer:

| Your computer | File | How to install |
| --- | --- | --- |
| Windows 10/11 | `AZK-CyberLab-Setup-<version>.exe` | Double-click. It installs and opens by itself. |
| Mac (Apple Silicon: M1/M2/M3/M4) | `AZK-CyberLab-<version>-arm64.dmg` | Open, drag AZK-CyberLab into Applications. |
| Mac (Intel) | `AZK-CyberLab-<version>.dmg` | Open, drag AZK-CyberLab into Applications. |
| Linux | `AZK-CyberLab-<version>.AppImage` | Make it executable, then run it. |

## Updates

Installed copies check for new versions automatically and ask you to restart
when an update is ready (Help → Check for Updates… checks on demand).
